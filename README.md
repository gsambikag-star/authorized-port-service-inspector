
# Authorized Local Port & Service Inspector

## Overview
A Python-based defensive network inspection tool designed to identify open ports and associated services on the local machine.

## Objective
To inspect localhost (127.0.0.1) for open ports using Python socket programming while following strict safety restrictions.

## Technologies Used
- Python
- Socket Programming
- Git and GitHub

## Project Status
Phase 1 - Project Setup Completed

## Safety
This tool is restricted to scanning localhost (127.0.0.1) only.
